# Love8 投放 Web 体验稿

这是根据 Figma `Untitled / Page 1` 还原的 App 式 Web 单页体验。主画布固定为 **402 × 874**，按 Figma 从左到右的顺序串联 18 个页面；顶部导航、顶部进度、卡片、底部 CTA、弹层和方案选择都沿用 Figma 的视觉参数。Web 预览已移除系统状态栏，并将内容整体上移；付费后的账号绑定和 App 下载引导也已经接入完整流程。

进度条只在 Figma 画板本身包含进度条的页面显示。进度值按主页面的实际顺序动态计算，因此经过品宣、产品作用等无进度条页面后，下一张有进度条的页面会继续使用最新进度。

## 页面顺序

性别 → 名字 → 年龄 → 在一起时间 → 距离 → 目的 → 需求 → 品宣 → 位置同步 → 状态同步 → 互动 → 小组件 → 故事回忆 → 产品作用 → 权益说明 → 价格方案 → 绑定账号 → 下载 App。

`design/manifest.json` 保存了页面顺序、Figma 节点 ID、哈希路由和导出素材的对应关系；`design/figma-document.json` 是本次读取的 Figma 文档结构快照。

## 运行

```bash
python3 -m http.server 4175
```

打开 <http://localhost:4175/>。桌面端会在居中的 App 画布中预览，窄屏会自动切换为全屏移动端比例。打开 <http://localhost:4175/?review=1> 可查看 Figma 页面索引和各页面状态。

默认使用全屏比例展示 App 画布；使用 `?fullscreen=0` 可切换为窗口预览。

## 项目结构

- `app-config.js`：页面流程、选项、功能页内容、资源映射和存储版本配置。
- `script.js`：路由、状态、模板渲染和交互逻辑，通过 ES Module 导入配置。
- `styles.css`：体验稿的布局和视觉样式。
- `assets/`：页面运行时资源；`design/` 仅用于设计映射和审阅，不属于生产资源。

状态存储当前使用 `love8-ob-v4`。首次加载时会兼容读取 `love8-ob-v3` 并迁移到新版本，避免升级后丢失体验稿中的填写内容。

移动端不使用自定义左右滑页，页面切换通过按钮和导航完成；选项、输入框、评价横滑区和弹层保留原生触摸行为。关键操作提供按压反馈和可用时的轻微触感反馈，页面切换同时更新无障碍播报。

移动端画布宽度始终跟随当前屏幕宽度，高度根据浏览器视口自适应；内容超出时在页面内部纵向滚动，不会为了适配高度缩窄画布。

如果环境中提供 npm，可运行基础语法检查：

```bash
npm run check
```

没有 npm 时也可以直接运行：

```bash
node --check script.js
node --check app-config.js
```

## 交互边界

姓名、性别、年龄、关系时长、距离、目的、需求、头像、价格方案和绑定表单会保存在当前会话中。头像选择支持本地图片预览，价格页的 Checkout 和 Restore 仅展示提示，不会提交支付；账号绑定会校验邮箱和姓名后进入下载引导页。访问码和下载按钮目前使用演示数据，接入投放时需要再补充正式的访问码接口、App Store 链接和 Google Play 链接。
